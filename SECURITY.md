# Security Policy

## Supported Versions

Only the latest commit on `main` is supported (currently 0.1.x). Please check that the issue still exists there before reporting.

## Reporting a Vulnerability

Please do not open a public issue for security problems. Email **jr5349@nyu.edu** with:

- a description of the problem and its impact
- steps or a proof of concept to reproduce it
- the commit or version you tested

You can expect an acknowledgement within 7 days.

## Security Updates

Fixes are made on a private branch where possible, merged into `main` through a pull request, and credited to the reporter unless they prefer otherwise. This is a small project maintained by one person, so there is no fixed fix deadline, but confirmed vulnerabilities take priority over other work.
